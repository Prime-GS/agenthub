# agenthub — кратко по-русски

**Один хаб нагрузки для всех ИИ-агентов на Linux-машине.** Каждая сессия агента (Claude Code, Codex, их
помощники) регистрируется в хабе. Каждый тяжёлый запуск — сборка, тесты, безголовый браузер, эмулятор,
стенд — сначала просит у хаба место. Работа идёт по убыванию приоритета, процессор между приоритетами делит
само ядро. Скриптов на кроне нет.

> **Статус: работают этапы M1–M3.** Сессии, очередь по приоритету с пуском по памяти, слайсы классов, клиент,
> который без хаба запускает команду сам, пауза пуска и остановка одного запуска при давлении памяти, оценки по
> прошлым запускам, пулы, старение и плагин для Claude Code (`claude --plugin-dir ./claude-code`): сборки и тесты
> агента сами ждут места в хабе, без строчки в `CLAUDE.md`. Дальше — другие агенты.
> Подробности и как попробовать — в английских документах ([README.md](README.md), [docs/](docs/)).

## Зачем

Несколько сессий на одной машине сами по себе запускают `tsc`, `jest`, `cargo build`, Playwright — и не знают
друг о друге. Память кончается, своп забивается, рабочий стол замирает, потом системный «убийца» процессов
(`systemd-oomd`) закрывает всю графическую сессию вместе со всеми агентами. Ограничения агентов действуют
только внутри одной сессии; между сессиями люди пишут каждый свой семафор, и ни один не совмещает приоритеты,
учёт памяти и общую картину на Linux.

## Как устроено

1. **Процессор — ядро.** Каждый класс приоритета (p0…p3) — свой slice (группа процессов systemd) со своим
   весом. Младший уступает сам, когда тесно; когда свободно — берёт всё.
2. **Память — хаб.** Запуск пускается, только если его ожидаемый пик (по прошлым запускам той же команды)
   помещается над запасом для рабочего стола. Остальные ждут в одной очереди по приоритету и времени.
3. **Давление — событие.** Хаб подписан на сигналы ядра о давлении памяти (PSI). Стало тесно — перестаёт
   пускать; стало опасно — останавливает самый новый запуск самого младшего класса и говорит его сессии почему.
4. **Видно всем.** `agenthub status` и строка статуса в агенте: кто что запустил, сколько ест, кто ждёт и почему.
5. **Без хаба работа не встаёт.** Хаб недоступен — команда идёт сразу в свой slice, веса продолжают работать.
6. **Хаб сам ничего не запускает** — только разрешает, наблюдает и останавливает запуски, о которых ему сказали.

Без root: всё работает под пользовательским systemd. Python 3.11+, только стандартная библиотека.
